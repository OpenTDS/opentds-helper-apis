# Contributing

**This project is open source, but it is not accepting contributions at this
time.**

The code is published under the [MIT License](LICENSE): you are free to use,
copy, modify, deploy and redistribute it, including in commercial work, as long
as the copyright and licence notice stay with the code.

What that means in practice:

- **Pull requests are not accepted.** Pull requests are switched off for this
  repository; please don't send patches by other routes either.
- **Forks are welcome.** If you need a change, fork the repository and make it
  in your copy. The MIT License allows that without asking.
- **Bug reports** may be opened as issues, but there is no commitment to
  respond to them or to fix them.
- **Security problems:** please report them privately, as described in
  [SECURITY.md](SECURITY.md), rather than in a public issue.

This may change in future. If it does, this file will set out how
contributions are licensed and reviewed.
